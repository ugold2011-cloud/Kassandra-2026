## Status Rules

* `PENDING` — not yet confirmed
* `SENT` — request sent
* `REPLY RECEIVED` — response received and requires review
* `CONFIRMED` — reservation/visit confirmed
* `CHANGE REQUIRED` — place requested a different date/time
* `DECLINED` — reservation not available

## Permanent Tracking Rule

For every reservation, always record:

* whether the request was sent
* exact date it was sent
* whether a reply was received
* exact date of reply
* result of the reply
* final reservation status
* any confirmation number or special instructions
